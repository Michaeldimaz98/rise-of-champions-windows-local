==============================================
  RISE OF CHAMPIONS v1.0.0 — Cara Menjalankan
==============================================

Game football manager simulator. Tidak perlu install apa-apa
selain Node.js.

SYARAT
-----
- Node.js versi 18 atau lebih baru (LTS disarankan).
  Cek:  node --version
  Download: https://nodejs.org/

CARA MAIN
---------
1. Buka terminal / cmd di folder ini.

2. Jalankan server:
     cd server
     npm start
   (atau: node src/http/server.js)

3. Buka browser:
     http://localhost:3000

4. Register akun (username + password), lalu bikin klub
   dan klik "Start Career". Selesai!

   Kalau port 3000 dipakai, jalankan dengan port lain:
     PORT=8080 npm start
   lalu buka http://localhost:8080

FITUR
-----
- Single-player: liga semusim penuh, taktik, training,
  transfer, youth academy, staff, fasilitas, kontrak.
- Daily reward: klaim tiap hari di home screen,
  streak 7 hari dapat bonus!
- Achievements: menu More > Rewards.
- PvP Friendly: challenge langsung by username (max 5/hari).
- Ranked Arena: menu More > PvP > Enter ranked queue.
  Kumpulkan rating Elo, naik tier (Bronze–Diamond)!
- Online League: bikin liga, teman join, menangkan
  hadiah top-3 tiap season!
- Events: menu More > Events — ikut event berhadiah,
  kumpulkan poin dari match selama event berlangsung.
- Shop: menu More > Shop — VIP, paket kas, kamp latihan,
  tim medis. (Mode demo: tanpa uang asli.)
- Analytics: menu More > Analytics — statistik permainanmu.

MAIN BARENG TEMAN
-----------------
Jalankan server di satu komputer yang bisa dijangkau
teman (satu WiFi / jaringan), lalu teman buka
http://<IP-komputer>:3000 di browser masing-masing.

DATA SAVE
---------
- Career + akun + liga + ranked + reward tersimpan di:
     server/data/
- Tiap matchday di-autosave. Bisa juga save manual dari
  menu More > Settings > Save now.

ISI PAKET
---------
- server/   : game engine + API (Node.js, tanpa dependensi)
- client/   : tampilan game (dibuka lewat browser)
- config/   : semua angka tuning game (bisa dioprek!)
- docs/     : dokumentasi tiap phase pengembangan

Selamat melatih! 🏆
